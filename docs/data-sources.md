# Phase 1 data provenance

The bundled Phailin sample contains six observed positions selected from Table 2.2.1, “Best track positions and other parameters of the Very Severe Cyclonic Storm Phailin,” in the India Meteorological Department Regional Specialised Meteorological Centre New Delhi Annual Review 2013. The source reports maximum sustained wind in knots; the `wind_speed_kph` values are rounded conversions using 1 knot = 1.852 km/h. The full source table remains authoritative.

Source: [IMD RSMC Annual Review 2013](https://rsmcnewdelhi.imd.gov.in/uploads/report/29/29_de488b_annual-review-2013.pdf).

The replay catalog also contains six source-table points each for Hudhud (2014) and Fani (2019). Their positions, pressures, and maximum sustained winds are sampled from the cited IMD RSMC best-track tables; wind values are rounded knot-to-km/h conversions using the same 1.852 factor. They are historical replays, not live observations.

Sources: [IMD RSMC Annual Review 2014](https://rsmcnewdelhi.imd.gov.in/uploads/report/29/29_6b0b3d_Annual%20Review-2014.pdf) and [IMD RSMC Fani preliminary report](https://rsmcnewdelhi.imd.gov.in/uploads/report/26/26_7122ae_Preliminary%20Report%20on%20ESCS%20FANI_15082020.pdf).
