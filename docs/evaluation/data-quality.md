# Data quality and freshness

The automated frozen-replay check validates required event and track fields, valid coordinates, parseable and ordered timestamps, consistent identifiers, duplicate observations, constructible track geometry, grid closure, required rainfall/elevation/population fields, non-negative feature values, and feature provenance metadata.

The dataset currently contains one event, six track points, two demonstration grids, and six feature values. The report is regenerated by `scripts/run_evaluation.py`.

All timestamps are historical. The UI exposes event source/timestamp, layer source/timestamp/resolution, forecast labels and uncertainty, simulation labels, and the Phase 7 stale-data indicator. The application must not represent this 2013 replay as live or current scientific data.
