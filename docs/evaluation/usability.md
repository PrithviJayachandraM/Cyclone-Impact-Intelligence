# Usability review

The primary local journey was reviewed against the one-cyclone demo: load Phailin, inspect observed and forecast tracks, toggle contextual layers, open location risk contributions, ask a grounded question, run the labelled simulation, compare maps, and run a local alert evaluation.

Observed track, forecast, and simulation are labelled with distinct visual/text cues. Risk details expose contributors; source/time metadata is displayed; the alert area exposes threshold and stale state. This is a lightweight developer review, not a study with external users.
